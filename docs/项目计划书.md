## 1. 项目概述

### 1.1 项目定位
这是一个**记录程序员开发学习过程**的个人技术博客，由两部分组成：
- **前台（读者看的）**：文章、专栏、TIL、学习路线、项目展示等
- **后台（博主用的）**：在浏览器里在线写作、管理全部内容，**点击发布即上线**，不用再手写 md 文件并上传

### 1.2 目标用户
| 用户 | 诉求 |
|---|---|
| 博主本人 | 随时随地打开网页就能写；写作体验好（实时预览、粘贴图片、自动保存）；发布后立即生效 |
| 技术读者 | 内容好找（分类、标签、搜索），读起来舒服（代码高亮、目录） |
| 面试官 / HR | 快速了解博主的技术栈、项目和学习能力 |

### 1.3 技术栈
| 类别 | 选型 | 作用 |
|---|---|---|
| 网站框架 | Astro 5.x（服务端渲染模式） | 前台页面和后台页面都用它 |
| 交互组件 | React（只用在后台编辑器等需要交互的地方） | 编辑器、拖拽排序、表单 |
| 语言 | TypeScript | 类型安全 |
| 样式 | Tailwind CSS | 包含深色模式 |
| 数据库 | Supabase（PostgreSQL） | 存放文章、分类、标签等全部内容 |
| 登录认证 | Supabase Auth | 后台只允许博主本人登录 |
| 图片存储 | Supabase Storage | 存放文章图片、封面、头像 |
| Markdown 编辑器 | 基于 CodeMirror 6 的 Markdown 编辑器 | 后台写作 |
| Markdown 渲染 | remark / rehype + Shiki | 把 Markdown 转成网页，并做代码高亮 |
| 评论 | Giscus | 基于 GitHub Discussions |
| 部署 | Vercel | 推送代码后自动部署，自带全球 CDN |
| 定时任务 | GitHub Actions | 数据库保活、定期备份 |

### 1.4 系统架构

```
              ┌────────────────────────── Vercel ──────────────────────────┐
  读者 ──────▶ │  前台页面（服务端渲染 + CDN 缓存）                           │
              │                                                            │
  博主 ──────▶ │  后台 /admin（需要登录）   ──  接口 /api/*（权限校验）       │
              └───────────────────────────────┬────────────────────────────┘
                                              │
              ┌────────────────────────── Supabase ────────────────────────┐
              │  PostgreSQL 数据库  │  Auth 登录认证  │  Storage 图片存储    │
              └────────────────────────────────────────────────────────────┘

  GitHub 仓库 ──推送──▶ Vercel 自动部署（只有改网站代码时才需要推送，写文章不用）
  GitHub Actions ──定时──▶ 数据库保活 / 每周备份
```

**关键设计**
1. **写文章不再涉及 Git**：内容全部存在数据库里；只有改网站功能或样式时才需要推送代码。
2. **保存时就把 HTML 渲染好**：保存文章时，后端把 Markdown 转成 HTML（包括代码高亮和目录）一起存进数据库。读者访问时直接读取，速度快。
3. **CDN 缓存加主动刷新**：前台页面由 CDN 缓存。发布或修改文章时主动刷新相关页面的缓存，**发布后几秒内全站生效**。
4. **数据库层权限隔离**：用 Supabase 的行级安全策略（RLS）做两层限制：
   - 未登录的访客只能读取“已发布”的内容
   - 只有博主账号可以新增、修改、删除

### 1.5 访问地址
- 前台：`https://<你的域名>`（没有域名时临时用 `xxx.vercel.app`）
- 后台：`https://<你的域名>/admin`

### 1.6 费用预估
| 项目 | 费用 | 说明 |
|---|---|---|
| Vercel Hobby | 免费 | 适合个人非商业项目 |
| Supabase Free | 免费 | 数据库 500MB、图片存储 1GB、每月流量 5GB，个人博客够用 |
| 域名（建议购买） | 约 50–80 元/年 | 解决国内访问 vercel.app 不稳定的问题 |

## 3. 前台功能详细说明

### 3.0 全局通用功能

#### 3.0.1 顶部导航栏
- 左侧是 Logo 和站点名，点击回到首页；中间是主导航，当前栏目高亮；右侧是搜索、主题切换和 GitHub 图标
- 页面滚动时导航栏吸顶，背景半透明并带毛玻璃效果
- 移动端（宽度 < 768px）收起为汉堡菜单，点开后是抽屉式菜单
- **博主登录状态下**，右上角额外显示“进入后台”入口；在文章页还会显示“编辑本文”按钮，点击直接跳到该文章的编辑页

#### 3.0.2 页脚
版权信息、快捷链接（分类 / 标签 / 归档 / RSS）、社交链接、“Built with Astro”。内容可以在后台的站点设置里修改。

#### 3.0.3 主题切换
- 三种模式：浅色 / 深色 / 跟随系统，默认跟随系统；选择结果保存在本地
- 页面加载时不会出现主题闪烁；代码高亮和评论区的主题跟着一起切换

#### 3.0.4 全站搜索（第三期）
- 点击搜索按钮或按 `Ctrl/⌘ + K` 打开搜索弹窗
- 输入时实时搜索（停止输入 300ms 后才发请求），搜索范围是文章和 TIL 的标题、摘要、正文
- 结果显示标题、命中的片段（关键词高亮）和类型（文章 / TIL）
- 支持键盘 `↑ ↓` 选择、`Enter` 跳转、`Esc` 关闭；按 `Enter` 但没有选中任何结果时，进入 `/search` 完整结果页
- 实现方式：在数据库里做模糊检索（PostgreSQL 的 pg_trgm 扩展），支持中文

#### 3.0.5 其他
- 返回顶部按钮；页面切换时的过渡动画
- 每个页面都有独立的 SEO 信息（title、description、Open Graph、canonical）
- 响应式布局，适配手机、平板和桌面

| ⑥ 正在学习 | 学习路线中状态为“学习中”的技术项和进度条 |

- 页头显示总数；有一排分类筛选

### 3.3 文章详情 `/posts/[slug]`（核心页面）

**文章头部**：标题、发布日期、更新日期、分类、阅读时长、字数、**阅读量**、标签、封面；如果文章属于某个专栏，显示提示条“本文是《XXX》第 N 篇，共 M 篇”。

**正文阅读**：正文宽度约 720px，行高 1.8，针对中文排版做优化；标题旁有锚点链接；图片懒加载，点击可放大查看；外部链接在新窗口打开；宽表格可以横向滚动。

**代码块**
| 功能 | 说明 |
|---|---|

| 语言标签 | 右上角显示语言名 |

| 行高亮 / Diff | 可以高亮指定行，显示增删行样式 |

**阅读进度条**：显示在页面顶部。

**文章底部**

- 专栏导航（列出专栏全部章节，当前章节高亮）
- 上一篇 / 下一篇
- 相关推荐：标签重合最多的 3 篇
- 评论区（第三期，Giscus）

**阅读量统计规则**：同一访客对同一篇文章 24 小时内只计一次；明显是爬虫的访问不计入。

### 3.6 分类

### 3.7 标签
- `/tags`：标签云，文章越多字号越大，标签后显示数量
- `/tags/[slug]`：该标签下的文章和 TIL，分两个区域显示

### 3.8 归档 `/archive`

- 按“年 → 月”的时间线排列，年份可以折叠

- 按领域分组。每个技术项显示：名称、图标、状态（计划中 / 学习中 / 已掌握）、进度条、学习时间段、关联的文章 / 专栏 / TIL、心得备注

### 3.10 项目 `/projects`
- 卡片网格。每个项目显示：截图、名称、简介、技术栈、GitHub 链接 / 演示链接、状态

### 3.11 关于 `/about`

### 3.12 404 页面

## 4. 后台功能详细说明

### 4.1 登录 `/admin/login`
- 登录方式：**GitHub 账号一键登录**（推荐），也可以用邮箱 + 密码
- **白名单**：只有站点设置中配置的博主邮箱或 GitHub 账号能进入后台；其他人即使登录成功也会被拒绝，并提示“无权限”
- 登录状态保持 7 天；可以手动退出
- 所有 `/admin/*` 页面和写操作的 `/api/*` 接口都会校验登录状态和权限。未登录时跳转到登录页，并且登录后会回到原来的页面
- 连续 5 次登录失败后锁定 15 分钟（仅邮箱登录方式）

### 4.2 仪表盘 `/admin`
| 模块 | 内容 |
|---|---|
| 数据卡片 | 已发布文章数、草稿数、TIL 数、专栏数、总阅读量、总点赞数 |
| 快捷操作 | “写文章”“记 TIL”两个大按钮 |
| 最近编辑 | 最近修改的 5 篇内容，点击继续编辑 |
| 草稿箱 | 所有未发布的草稿 |
| 定时发布队列 | 即将发布的文章和发布时间 |
| 热门文章 | 阅读量前 10 |
| 写作趋势 | 最近 12 个月每月的发文数柱状图（第三期） |

### 4.3 文章管理 `/admin/posts`
- **列表列**：标题、状态（草稿 / 已发布 / 定时发布）、分类、标签、阅读量、点赞数、更新时间、操作
- **搜索**：按标题关键词
- **筛选**：状态、分类、标签、所属专栏
- **排序**：更新时间、发布时间、阅读量
- **单条操作**：编辑、预览、在前台查看、置顶 / 取消置顶、复制为新草稿、删除（进入回收站）
- **批量操作**：批量发布、批量转为草稿、批量修改分类、批量删除
- 分页，每页 20 条

### 4.4 文章编辑器 `/admin/posts/new`、`/admin/posts/[id]`（核心功能）

#### 4.4.1 页面布局
```
┌──────────────────────────────────────────────────────────────────┐
│ ← 返回   [标题输入框...........................]   已保存 10:32   │
│                                [预览] [保存草稿] [发布 ▾]        │
├──────────────────────────────┬──────────────────────┬────────────┤
│  Markdown 编辑区             │  实时预览区           │ 文章设置    │
│  (带工具栏)                  │  (和前台样式一致)     │ (可收起)    │
│                              │                       │            │
└──────────────────────────────┴──────────────────────┴────────────┘
```
- 支持三种视图切换：**只看编辑 / 编辑 + 预览 / 只看预览**；还有专注模式（全屏，隐藏其他界面）
- 编辑区和预览区**同步滚动**
- 移动端只显示单栏，通过“编辑 / 预览”标签切换

#### 4.4.2 编辑区
- Markdown 语法高亮、自动缩进、括号补全
- **工具栏**：标题、加粗、斜体、删除线、行内代码、代码块（可以选择语言）、引用、有序 / 无序列表、任务列表、链接、图片、表格、提示块、分割线
- **快捷键**：`⌘B` 加粗、`⌘I` 斜体、`⌘K` 插入链接、`⌘S` 保存、`⌘⇧P` 切换预览
- 底部状态栏显示字数、预计阅读时长、光标所在行号

#### 4.4.3 图片上传
- 三种方式：**直接粘贴截图**、**把图片拖进编辑区**、点击工具栏选择文件
- 上传前在浏览器里自动压缩：宽度大于 1920px 时缩小，并转换为 WebP 格式
- 上传过程中，光标处显示“上传中…”占位；成功后替换为图片的 Markdown 语法
- 单张图片上限 5MB；只接受 jpg / png / gif / webp / svg
- 上传的图片自动登记到媒体库

#### 4.4.4 文章设置面板（右侧）
| 字段 | 说明 |
|---|---|
| 链接别名 slug | 根据标题自动生成（中文转拼音或英文），可以手动修改；保存前检查是否重复 |
| 摘要 | 可选；不填时自动截取正文前 120 字 |
| 分类 | 下拉单选；可以在这里直接新建分类 |
| 标签 | 输入时自动补全已有标签；按回车可以新建标签 |
| 专栏 | 下拉选择所属专栏，并填写第几篇 |
| 封面图 | 上传或从媒体库选择 |
| 发布时间 | 默认是当前时间；设为未来时间就是定时发布 |
| 置顶 | 开关 |
| 允许评论 | 开关 |

#### 4.4.5 保存与发布
- **自动保存**：内容变化后每 30 秒自动保存到数据库（作为草稿版本），顶部显示“已保存 HH:mm”或“保存中…”
- **本地兜底**：每次输入都同时写入浏览器本地存储。网络断开或页面意外关闭后，再次打开会提示“发现未保存的内容，是否恢复？”
- **离开提醒**：有未保存的内容时关闭或离开页面，会弹出确认提示
- **发布按钮**的下拉选项：
  - 立即发布：状态改为已发布，刷新前台缓存，几秒后线上可以看到
  - 定时发布：选择未来的时间；到点后前台自动显示，不需要额外的定时任务
  - 更新：已发布的文章修改后点击，立即生效，并记录更新时间
  - 转为草稿：从前台下架
- **发布前校验**：标题、分类、正文都不能为空；slug 不能重复。校验不通过时高亮对应字段并给出提示

#### 4.4.6 预览草稿
点击“预览”会在新窗口打开**和前台完全一样的文章页**，即使文章还是草稿也能看，页面顶部有“草稿预览”提示。只有登录后才能访问。

#### 4.4.7 历史版本（第三期）
- 每次手动保存或发布时记录一个版本，最多保留最近 30 个
- 版本列表显示时间和字数变化；可以查看某个版本与当前内容的差异，也可以一键恢复到该版本

### 4.5 TIL 管理 `/admin/til`
- 页面顶部是**快速记录框**：标题、正文（简化版 Markdown 编辑器，也支持粘贴图片）、标签。点“发布”立即生效，**目标是几秒钟记完一条**
- 下方是 TIL 列表，可以编辑、删除，按标签筛选

### 4.6 专栏管理 `/admin/series`
- 新建 / 编辑专栏：名称、slug、简介、封面、状态（连载中 / 已完结）、是否精选
- **章节排序**：进入专栏后，通过拖拽调整文章顺序，保存后自动更新每篇文章的序号
- **计划章节**：可以添加还没写的章节标题，前台会显示为灰色的“计划中”
- 专栏下还有文章时，不能直接删除，需要先移出文章

### 4.7 分类管理 `/admin/categories`
- 增、删、改：名称、slug、图标、简介
- 拖拽调整显示顺序
- 删除有文章的分类时，必须先选择把这些文章转移到哪个分类

### 4.8 标签管理 `/admin/tags`
- 列表显示标签名、slug、使用次数
- 支持重命名、修改 slug、删除
- **合并标签**：例如把 “JS” 合并进 “JavaScript”，所有关联文章自动改为新标签
- 一键清理没有被任何内容使用的标签

### 4.9 学习路线管理 `/admin/roadmap`
- 按领域分组的列表，领域可以新增、重命名、排序
- 技术项字段：名称、图标、状态、进度（滑块 0–100）、开始 / 结束时间、心得备注、**关联内容**（可以搜索并选择文章 / 专栏 / TIL）
- 支持拖拽排序

### 4.10 项目管理 `/admin/projects`
- 字段：名称、简介、封面、技术栈（多个标签）、GitHub 地址、演示地址、状态、是否精选
- 支持拖拽排序

### 4.11 媒体库 `/admin/media`
- 网格展示所有已上传的图片，显示缩略图、文件名、大小、尺寸、上传时间
- 操作：上传（可以多选）、复制链接、复制 Markdown 语法、删除
- **引用检查**：删除前检查图片是否被文章使用；正在使用时给出提示并列出引用它的文章
- 顶部显示已用存储空间（比如“已用 120MB / 1GB”）

### 4.12 回收站 `/admin/trash`
- 删除的文章和 TIL 先进入回收站，**30 天后自动彻底删除**
- 可以恢复或立即彻底删除

### 4.13 站点设置 `/admin/settings`
| 分组 | 设置项 |
|---|---|
| 基本信息 | 站点名称、副标题 / Slogan、站点描述（用于 SEO）、Logo、Favicon |
| 博主信息 | 昵称、头像、一句话介绍、技术栈图标列表 |
| 社交链接 | GitHub、邮箱、掘金、知乎等（可以增删） |
| 关于页 | Markdown 正文 |
| 展示设置 | 每页文章数、首页各模块的开关和显示数量 |
| 评论设置 | Giscus 配置、全站评论开关 |
| 权限 | 后台白名单（邮箱 / GitHub 用户名） |
| 数据 | **一键导出全部内容**（打包下载 md 文件和图片列表）；从 md 文件批量导入 |

修改保存后，前台立即生效。

### 5.3 安全策略（行级安全 RLS）
| 数据 | 匿名访客 | 博主（已登录且在白名单中） |
|---|---|---|
| 已发布的文章 / TIL | 只读 | 读写 |
| 草稿、定时发布中、回收站中的内容 | **不可见** | 读写 |
| 分类、标签、专栏、路线、项目、设置 | 只读 | 读写 |
| 阅读记录、点赞记录 | 只能通过受控接口增加，不能直接读写 | 只读统计 |
| 图片存储 | 只读 | 上传和删除 |

- 数据库的最高权限密钥**只保存在服务端环境变量里**，不会出现在浏览器代码中
- 点赞和阅读量接口有频率限制，防止刷数据

## 11. 风险与注意事项

| 风险 | 影响 | 应对 |
|---|---|---|
| 国内访问 `vercel.app` 不稳定 | 读者打不开网站 | **绑定自己的域名**；如果主要读者在国内并且要求高速访问，以后可以迁移到国内云服务器（需要备案） |
| Supabase 免费版 7 天无活动会暂停 | 网站不可用 | 用定时任务保活（见第 9 节） |
| Supabase 免费版没有自动备份 | 数据丢失风险 | 每周自动备份，并提供手动导出 |
| 免费额度用完（1GB 图片存储） | 无法上传图片 | 上传前压缩成 WebP；媒体库显示用量；必要时把图片迁移到其他对象存储 |
| 后台被攻击 | 内容被篡改 | 白名单 + 数据库行级安全 + 接口权限校验 + 频率限制 |
| 中文 slug | 链接难看 | 自动转成拼音或英文，并允许手动修改 |
| 本地调试误改线上数据 | 数据污染 | 开发环境和线上环境使用不同的数据库 |
